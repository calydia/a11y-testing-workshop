# MVP content-scope audit implementation plan

## Goal

Produce an evidence-based audit of whether the current Accessibility Testing Lab content forms a coherent MVP for people learning to perform their first practical accessibility review.

## Task 1: Establish the current content inventory

### Files

- Add: `docs/mvp-content-scope-audit-2026-08-14.md`

### Work

1. Inventory every published Learning path, Testing method, Exercise, and Testing journey.
2. Record routes, levels, durations, prerequisites, relationships, and authored order.
3. Confirm the public promise expressed by Home and About.
4. Note deliberate scope boundaries recorded in approved design specifications.

## Task 2: Build the beginner capability matrix

### Work

1. Map the ten approved beginner-workflow capabilities to paths, methods, Exercises, journeys, and supporting guidance.
2. Evaluate accuracy, independent practice, interpretation guidance, realistic application, and discoverability.
3. Distinguish dedicated coverage from capabilities adequately taught inside broader pages.
4. Record gaps, overlaps, and weak transitions without creating artificial one-to-one page requirements.

## Task 3: Classify content gaps and opportunities

### Work

1. Identify launch-critical gaps that prevent a coherent first-review workflow.
2. Identify valuable additions for shortly after launch.
3. Identify specialist or comprehensive topics suitable for later expansion.
4. Record intentionally out-of-scope areas and explain why their deferral is reasonable.
5. Apply the approved new-content threshold before recommending another public page.
6. Recommend at most one launch-critical new Testing method unless evidence demonstrates a fundamentally incomplete beginner promise.

## Task 4: Assess sequencing and cross-linking

### Work

1. Check whether visitors can move from paths to methods, Exercises, and journeys in a coherent order.
2. Identify missing or misleading prerequisite, practice, and next-step links.
3. Separate content needing refinement from content needing a new page.
4. Keep retained legacy cleanup distinct from public-content recommendations.

## Task 5: Write conclusions and recommended sequence

### Work

1. Lead with a clear MVP-readiness conclusion.
2. Present the current inventory and capability matrix concisely.
3. Separate observed evidence from evaluative judgment.
4. Make every recommendation actionable and assign its approved classification.
5. Recommend an ordered set of remaining pre-launch content tasks without expanding each task into its own implementation design.
6. State assumptions and evidence limitations explicitly.

## Task 6: Verify the audit

1. Recheck all counts, routes, titles, levels, durations, and relationships against the collections.
2. Check that every matrix mapping points to real current content.
3. Scan recommendations for duplicates of existing material.
4. Confirm that every launch-critical recommendation serves the primary beginner audience.
5. Scan for placeholders, contradictions, ambiguous recommendations, and accidental legacy-cleanup scope.
6. Run `git diff --check`.
